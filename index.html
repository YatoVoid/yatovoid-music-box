      How to use it

      Mouse

      Click empty spaceAdd a note (length from Note)
      Drag a noteMove it, hearing each pitch
      Drag a note's right edgeMake it longer or shorter
      Shift + drag empty spaceSelect a group of notes
      Shift / Ctrl + click a noteAdd or remove it from the selection
      Right-click or double-clickDelete a note
      Click the bar numbersChoose where playback starts
      Click a key on the leftHear that pitch

      Keyboard

      SpacePlay / stop
      Ctrl C / X / VCopy, cut, paste at the mouse position
      Ctrl DDuplicate the selection right after itself
      Ctrl ASelect all notes
      Ctrl Z / Ctrl YUndo / redo
      Ctrl SSave to My songs
      DeleteDelete selected notes
      ↑ ↓ / ← →Move selection by a semitone / a 16th
      Shift + arrowsMove by an octave / a beat
      EscClear selection, close panels

      On a Mac, use Cmd instead of Ctrl. The chord picker above each bar adds an automatic bass line and chord backing.
